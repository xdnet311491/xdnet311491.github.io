# ============================================================
#  env.txt の書き方 (この env.example.txt をコピーして env.txt を作る)
# ============================================================
#  ・env.txt は osaito フォルダ (build.py と同じ場所) に置く。GitHubには上がらない (.gitignore に自動で入る)。
#  ・「#」で始まる行はコメント。空行は無視される。
#  ・1つのAPIは「@名前」の行から始める。次の「@」までが1件。
#  ・項目は「項目名: 値」の形 (「:」「：」「=」のどれでもよい)。
#  ・メモなど複数行にしたいときは、次の行を「字下げ (スペース)」して続ける。
#
#  使える項目名 (日本語でも英語でもOK):
#    url / endpoint / エンドポイント ...... APIのURL (コピーボタン付き)
#    key / キー / token / トークン ......... 鍵 (暗号化される。下の注意を読むこと)
#    secret / password / パスワード / 秘密… 名前に「key・キー・token・トークン・secret・
#                                            password・パスワード・秘密」を含む項目は全部暗号化される
#    limit / 制限 / 無料枠 / 料金 / plan ... 制限・料金
#    link / リンク / 管理画面 / console ... 管理画面などのリンク (押すと開く)
#    expires / 期限 ........................ 期限
#    tag / タグ ............................ カンマ区切りで複数 (例: tag: AI, 無料)
#    memo / メモ / note / 備考 ............. 自由メモ (複数行OK)
#    そのほか好きな名前 ..................... そのまま「名前: 値」で表示される
#
#  ★ 注意 (大事)
#    ・キー系の項目は、dev_password.txt のパスワードから作った鍵で暗号化してから index.html に入れます。
#      ブラウザで開発者機能に入り、一覧の「解除」にパスワードを入れたときだけ読めます。
#    ・ただし index.html は公開されます。暗号化の強さは「パスワードの長さ」で決まるので、
#      キーを入れるなら dev_password.txt のパスワードは長く (12文字以上・推測されにくく) してください。
#    ・URL・メモ・制限などは暗号化されません (ページのソースを見れば誰でも読めます)。
#      メモにも秘密を書きたいときは、項目名を「秘密メモ:」のように「秘密」を含む名前にします。
#    ・本当に重要なキー (お金がかかるもの・本番用) は、ここに書かない方が安全です。
# ============================================================
